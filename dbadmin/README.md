# Innova DB Studio

Собственный веб-просмотрщик и редактор базы данных Innova365 (аналог phpMyAdmin для PostgreSQL).
Отдельный сервис на порту **8200**: свой backend (Node + Express + pg), свой frontend (React + CodeMirror), одна Docker-сборка.

## Что умеет
- **Обзор** — размер базы, подключения, кэш, размеры таблиц, активные сессии (отмена / завершение), список баз.
- **Таблицы** — просмотр с сортировкой, фильтрами и WHERE; правка ячеек двойным щелчком; вставка, дублирование, удаление строк (атомарно, по первичному ключу или ctid); экспорт CSV / JSON / SQL.
- **Структура** — колонки, типы, индексы, ограничения, внешние ключи, триггеры; добавить / переименовать / изменить тип / удалить колонку; создать / удалить индекс; TRUNCATE, DROP, VACUUM.
- **SQL-консоль** — подсветка и автодополнение таблиц и колонок, несколько запросов за раз, EXPLAIN / ANALYZE, история, сохранённые запросы, готовые шаблоны, экспорт результата.
- **Процедуры** — функции и процедуры: просмотр, правка (CREATE OR REPLACE), запуск с аргументами, удаление; триггеры с включением / выключением.
- **Пользователи** — роли PostgreSQL: атрибуты, пароль, лимит подключений, группы, матрица привилегий на таблицы.
- **Экспорт / импорт** — дамп базы (pg_dump) и импорт .sql (psql, одной транзакцией).

## Безопасность
- Вход только под учётной записью PostgreSQL (`POSTGRES_USER` / `POSTGRES_PASSWORD` из `.env`). Пароль хранится только в памяти процесса.
- После входа включён режим **«Только чтение»**; запись разрешается переключателем в шапке (PostgreSQL сам отклоняет изменения в этом режиме).
- Сессия — cookie `HttpOnly` + `SameSite=Strict`, закрывается после 30 минут бездействия; защита от перебора (6 попыток в минуту); заголовок `X-Requested-With` обязателен для всех изменяющих запросов (защита от CSRF); имена таблиц и колонок проверяются по каталогу.
- Все входы и изменяющие операции пишутся в лог контейнера: `docker compose logs dbadmin`.
- **Порт 8200 даёт доступ к базе — закройте его для чужих сетей** (файрвол по IP) или публикуйте только на localhost: `DBADMIN_BIND=127.0.0.1` в `.env` и заходите через SSH-туннель `ssh -L 8200:localhost:8200 user@сервер`.

## Запуск
```bash
docker compose up -d --build dbadmin
```
Открыть: http://localhost:8200 (на сервере — http://IP:8200).

## Разработка
```bash
cd dbadmin/backend  && npm i && npm run dev    # API на :8200 (нужны DB_HOST, DB_PORT, DB_NAME)
cd dbadmin/frontend && npm i && npm run dev    # интерфейс на :5180, проксирует /api на :8200
```
