# Innova365 POS: автономная сборка

## Состав установщика

- Electron и собранный React интерфейс.
- Скомпилированный Express API с Node зависимостями и Prisma Client.
- Переносимые бинарники PostgreSQL 16 для Windows x64: `initdb`, `pg_ctl`, `psql`, `pg_dump`, библиотеки и служебные файлы.
- Подготовленный дамп одного заведения и его паспорт `offline-manifest.json`.
- Локальный агент печати. Драйвер конкретного принтера Windows при необходимости устанавливается отдельно.

При первом запуске создаются база, случайные ключи и пароль БД в пользовательской папке приложения. Данные импортируются один раз. База и API слушают только `127.0.0.1`. Вход, меню, столы, заказы, оплата, склад и отчёты обращаются к локальному API без сервера и интернета. При штатном выходе сохраняется резервная копия; последние семь копий остаются в `userData/offline/backups`.

## Сборка для заведения

1. Установить зависимости командой `npm ci` в `frontend`, `backend` и `native-innova365`; выполнить `npx prisma generate` в `backend`.
2. Поместить официальные Windows x64 бинарники PostgreSQL 16 в `native-innova365/vendor/pgsql/{bin,lib,share}`. В установщик включаются файлы лицензий поставщика.
3. Создать дамп именно этого заведения командой `node tools/prepare-offline-seed.js <путь-к-дампу.sql>`. Скрипт удаляет прежние привязки устройств, задания печати, журнал и серверный ключ активации, затем создаёт `vendor/seed.sql` и `vendor/offline-manifest.json`.
4. Выполнить `npm run test:offline`, затем `npm run dist`. Результат: `dist/Innova365-Setup-1.2.0-beta.2.exe`.

Текущий дамп принадлежит заведению Meyiz. Установщик содержит хеши паролей сотрудников и данные этого заведения. Для другого кафе необходимы отдельный дамп и отдельная сборка.

## Ограничения

- Продажи работают без сети. Автоматическая синхронизация отчётов и телеметрии с `innova365.kz` ещё не реализована. Две независимые установки пока имеют разные базы.
- Таймер оплаты за месяц показывает статус подписки. Подтверждение оплаты и выдача автономной лицензии требуют отдельного механизма.
- Успех отправки задания в Windows не подтверждает полный физический вывод чека. Для каждого нового принтера нужен тест чека, кириллицы, QR и отреза.
- Удаление приложения оставляет папку с данными. Для переноса кассы нужны база или резервная копия вместе с `local-secrets.json`.
