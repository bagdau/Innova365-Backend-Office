# Innova365 Desktop

Настольное приложение Innova365 на Electron для кассового компьютера. Это **не отдельная касса, а клиент**: внутри открывается ваша касса с сервера
(`innova365.kz` или адрес в локальной сети), поэтому все обновления веб-части приходят сами, без переустановки. Приложение добавляет то, чего не может браузер:

| Что даёт | Вместо чего |
|---|---|
| **Встроенный агент печати** на `127.0.0.1:9101`: чеки ESC/POS идут на USB-, Windows- и сетевые принтеры | отдельная установка `print-agent` + `install-agent.bat` + правка `allowed-origins.txt` |
| Запуск «как программа»: окно, полный экран, **режим киоска**, автозапуск с Windows, значок в трее | `start-pos-browser.bat` и флаги Chrome |
| **WebUSB-печать** работает без флагов и без Zadig-настроек браузера | `--unsafely-treat-insecure-origin-as-secure` |
| Экран **«нет связи»** с автоповтором (каждые 5 с) вместо белой страницы браузера | — |
| **PIN** на настройки и на выход из киоска | — |
| Печать документов (A4, отчёты) **без диалога** на выбранный принтер (по желанию) | `--kiosk-printing` |
| Окно **Office** из трея | отдельная вкладка браузера |

Веб-касса при этом **не меняется**: протокол агента тот же (`/health`, `/printers`, `/best`, `/discover`, `/print`), в настройках кассы остаётся «Принтер этого компьютера (агент)» → `auto`.

## Быстрый старт

```bash
cd native-innova365
npm install
node node_modules/electron/install.js   # если Electron не скачался при npm install (бинарник качается с GitHub)
npm start
```

При первом запуске откроется мастер: введите адрес кассы (`innova365.kz` или `192.168.1.10:8080`) → «Сохранить и запустить».
Настройки позже: **Ctrl+Shift+S** или значок в трее → «Настройки…».

### Установщик для кассы

```bash
npm run dist          # → dist/Innova365-Setup-1.0.0.exe (NSIS, установка на пользователя, ярлыки)
```

Сборка скачивает Electron и инструменты electron-builder, нужен доступ к GitHub. Подпись кода не настроена: Windows SmartScreen покажет предупреждение,
пока установщик не подписан сертификатом (нужен ваш сертификат — `win.certificateFile` в секции `build`).

## Печать

1. Подключите принтер и поставьте драйвер Windows (для USB-термопринтеров подойдёт и «Generic / Text Only»); напечатайте тест из Windows.
2. **Настройки → Печать**: агент включён, в таблице подсвечен принтер, который выберет «Авто» (кассовый термопринтер; PDF/XPS/Fax и принтеры «не в сети» не выбираются).
3. Блок **«Пробная печать»**: выберите принтер, ширину (58/80 мм) и кодировку → «Напечатать пробный чек». Русские буквы вышли «кракозябрами» — выберите CP1251 или «Латиница» (в кассе та же настройка).
4. В кассе: **Настройки → Принтеры** → «Принтер этого компьютера (агент)», принтер `auto`.

Сетевой принтер (порт 9100): в пробной печати выберите «Сетевой принтер по IP…» либо укажите `IP[:порт]` в кассе — агент передаст байты в принтер. Разрешены только адреса локальной сети.

### Если раньше стоял `print-agent`

Порт 9101 занят старым агентом — приложение покажет «порт занят», кассе это не мешает (она печатает через старый агент). Чтобы перейти на встроенный:
запустите `print-agent/uninstall-agent.bat`, затем перезапустите Innova365 (или «Настройки → Печать → Перезапустить»).

### Печать с сервера или другой кассы на этот компьютер

Включите **«Принимать запросы из локальной сети»**, разрешите порт в брандмауэре Windows (`netsh advfirewall firewall add rule name="Innova365 agent" dir=in action=allow protocol=TCP localport=9101 profile=private`)
и укажите в кассе адрес `IP-компьютера:9101` и **токен** (Настройки → Печать → «Токен доступа»). Без токена запросы из сети отклоняются; со страниц — только с разрешённых адресов.

## Режим киоска и PIN

* **Настройки → Окно и запуск**: «Запускать на весь экран», «Режим киоска», «Крестик сворачивает в трей», «Запускать вместе с Windows».
* **Настройки → Безопасность**: PIN (4–16 знаков). С PIN настройки и выход из киоска открываются только после ввода; 5 неверных попыток подряд — пауза 30 секунд. PIN хранится в виде хеша (scrypt).
* Без PIN киоск закрывается значком в трее → «Выход». Забыли PIN — удалите файл настроек (см. ниже), адрес кассы придётся ввести заново.

Горячие клавиши в окне кассы: **F11** — полный экран (кроме киоска), **F5 / Ctrl+R** — перезагрузить, **Ctrl+Shift+S** — настройки, **Ctrl + / − / 0** — масштаб, **Alt+←** — назад.

## Безопасность

* Страницы работают в изолированной среде: `contextIsolation`, `sandbox`, без `nodeIntegration`; мост `innova` (настройки) есть **только** у файлов приложения, сайту отдаётся лишь `innovaNative` (признак «десктоп» и версия).
* Внутри окна открывается только адрес кассы (и Office); любые другие ссылки уходят в обычный браузер, `file://` и `javascript:` блокируются. Если сервер сам перенаправил кассу (http → https, IP → домен), новый источник считается доверенным до закрытия приложения.
* Сайту разрешены уведомления, полный экран, запись в буфер обмена и WebUSB; камера, микрофон, геолокация и прочее — запрещены.
* Агент слушает только `127.0.0.1` (если не включена сеть), проверяет `Host` (защита от DNS-rebinding), принимает запросы со страниц разрешённых адресов либо с токеном, ограничивает размер данных (2 МБ), сетевые принтеры — только из частных подсетей.
* Ошибки сертификата HTTPS не обходятся: сервер с самоподписанным сертификатом не откроется — используйте нормальный сертификат (Let's Encrypt) либо `http://` в локальной сети.

## Где что лежит

```
native-innova365/
├─ src/            главный процесс Electron: main.js (запуск), windows.js (окна, защита навигации), ipc.js, tray.js,
│                  session-setup.js (права, WebUSB), print-silent.js (печать документов без диалога), preload.js
├─ lib/            логика без Electron (тестируется отдельно): agent.js (HTTP-агент), rawprint.js (winspool/CUPS/сеть),
│                  printers.js (оценка принтеров), escpos.js (пробный чек), config.js, pin.js, url.js, log.js, ps/raw-worker.ps1
├─ frontend/       экраны приложения: settings.html/js (настройки), offline.html/js («нет связи»), ui.css
├─ build/          icon.png (рисуется build/make-icon.py)
└─ test/           автотесты (см. ниже)
```

Данные пользователя: `%APPDATA%\Innova365\` — `config.json` (настройки, токен агента, хеш PIN), `logs\app.log` (журнал; последние записи — «Настройки → О программе»).
Сеанс кассы (cookie, вход) хранится в профиле Electron в той же папке, поэтому после перезапуска входить заново не нужно.

## Тесты

```bash
npm run typecheck   # типы: код src/ и lib/ сверяется с типами Electron 45 (electron.d.ts)
npm test            # 55 автотестов на Node: агент, конфиг, PIN, ESC/POS, экраны (jsdom), главный процесс (подставной electron)
npm run test:app    # настоящий Electron: окно, мост, агент, preload в iframe, экран «нет связи» (10 проверок)
npm run test:ui     # настоящий Electron: мастер, настройки, реальный IPC, PIN, блокировка, печать документа (31 проверка)
```

`npm test` не требует Electron и принтера; `test:app` и `test:ui` запускают настоящее приложение с временной папкой данных и фальшивой «кассой» на `127.0.0.2`
(окна на секунды появятся на экране). Ничего не печатается; `SHOTS=папка npm run test:ui` сохранит снимки окон.

| Проверено автоматически | Остаётся проверить на вашем железе |
|---|---|
| Протокол агента: CORS/PNA, токен, источники, Host, лимиты, ретрансляция в сеть (на реальном TCP-сервере) | Печать на **реальный чековый принтер**: RAW-запись в winspool, отрезка, кодировка |
| Реальный PowerShell: список принтеров Windows, ошибка на несуществующем принтере | Выбор «Авто» на ваших моделях (правила — по названию и порту) |
| Настоящий Electron: окна, мост `innova`/`innovaNative`, IPC, PIN и блокировка, масштаб, автооткрытие после обрыва связи | WebUSB-печать (`select-usb-device`) на вашем принтере |
| Настоящий Chromium: страница на `http://` — безопасный контекст, обращается к агенту (CORS), `print` подменён в iframe | Печать документов без диалога на реальный принтер: размер бумаги и поля зависят от драйвера |
| Кодировки CP866/CP1251, пробный чек, настройки (валидация, атомарная запись), защита IPC/навигации/прав | Установщик (`npm run dist`) на чистой Windows, автозапуск, трей, режим киоска на кассовом мониторе |

## Обновление приложения

* **Веб-касса** обновляется на сервере как обычно (`docker compose up -d --build frontend`): приложение подхватит её сразу, у кассы есть и собственная проверка `/version.json`.
* **Оболочка** (это приложение) обновляется установщиком — запустите новый `Innova365-Setup-x.y.z.exe` поверх старого, настройки сохранятся.
  Автообновление (electron-updater) не подключено: ему нужен сервер выпусков (GitHub Releases или свой каталог), укажите, где вы хотите хранить установщики.

## Ограничения

* Сборка и запуск — Windows 10/11 x64. Linux/macOS: агент печатает через CUPS (`lp -o raw`), но не проверялось.
* Режим киоска не отключает системные сочетания Windows (Ctrl+Alt+Del, Win и т. п.) — для настоящего киоска используйте политики Windows («Assigned Access»).
* Приложение не подписано (см. «Установщик»).
