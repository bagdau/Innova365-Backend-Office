# Агент печати Innova365

Нужен для **USB-принтеров** (и любых принтеров, установленных в Windows). Сервер Innova365 работает в Docker и не видит USB-порты
компьютера, поэтому на ПК с принтером запускается этот маленький агент: он принимает чек от сервера и отправляет его в очередь Windows
в «сыром» виде (RAW) — так работают кассовые принтеры на ESC/POS.

Сетевым принтерам (с IP-адресом, порт 9100) агент **не нужен** — сервер печатает на них напрямую.



## Сервер в интернете: печать с кассы через локальный агент (рекомендуется)

Если Innova365 стоит на VPS, сервер не видит принтер вашей сети. Тогда чек печатает **браузер кассы**: байты ESC/POS берёт у сервера и отдаёт агенту на этом же ПК
(`127.0.0.1:9101`) — получается чёткий текст, правильная ширина, QR и обрезка (в отличие от печати через драйвер Windows, где страница превращается в картинку).

1. Скопируйте папку `print-agent` на кассовый ПК, **`install-agent.bat` — от имени администратора**.
2. В `allowed-origins.txt` должен быть адрес, по которому касса открывает Innova365 (например `http://194.32.142.75:8080`). Страницы не из списка печатать не смогут.
3. Открывайте Innova365 через **`start-pos-browser.bat http://адрес:8080`** (флаги: печать без диалога и доступ http-страницы к агенту на этом ПК).
4. В окне печати выберите «Принтер этого компьютера (агент)»: принтер — «Авто», ширина 80 мм, кодировка CP866. Кнопка «Проверка принтера» печатает тест.

Принтер на сетевом кабеле (IP): в том же окне выберите «Сетевой принтер по IP…» и введите адрес — агент передаст данные на порт 9100.

## Быстрая установка (рекомендуется)

Запустите **`install-agent.bat` от имени администратора** (ПКМ → «Запуск от имени администратора»). Один файл:
открывает порт 9101 в брандмауэре (только частные сети), добавляет агент в автозапуск Windows и запускает его в фоне.
Удалить — `uninstall-agent.bat`.

В Innova365 можно оставить имя принтера **`auto`**: агент сам выберет подключённый кассовый принтер
(не офлайн, не виртуальный PDF/XPS; приоритет — название «POS/XP/Receipt/Thermal…», порт USB/IP, принтер по умолчанию).
Проверить, что агент выберет: `GET /best` (заголовок `X-Token`).

## Печать без окна браузера

Чековые принтеры (сеть / USB-агент) печатают **без диалога**. Для документов, которые идут через «Окно системы (браузер)»,
используйте `start-pos-browser.bat http://IP-сервера:8080` — Chrome/Edge откроется как приложение с флагом `--kiosk-printing`
и будет отправлять печать сразу на принтер Windows «по умолчанию».

## Установка вручную (один раз на компьютер с принтером)

1. Ничего ставить не нужно: агент работает на PowerShell, который уже есть в Windows 10/11 (Node.js не требуется).
2. Установите принтер в Windows обычным способом (драйвер производителя или «Generic / Text Only»), напечатайте пробную страницу Windows.
3. Скопируйте папку `print-agent` на этот компьютер (кассовый моноблок) и запустите **`start-agent.bat`**.
   В окне появятся **адрес** и **токен** агента — они понадобятся в настройках.
4. Разрешите порт **9101** в брандмауэре Windows, если сервер Innova365 работает на другом компьютере:

   ```powershell
   New-NetFirewallRule -DisplayName "Innova365 print agent" -Direction Inbound -Protocol TCP -LocalPort 9101 -Action Allow -Profile Private
   ```

5. Чтобы агент стартовал вместе с Windows, положите ярлык на `start-agent.bat` в папку автозагрузки (`Win+R` → `shell:startup`).

## Настройка в Innova365

**Настройки → Принтеры → Добавить принтер → «USB / Windows»**

| Поле | Значение |
|---|---|
| Адрес агента | `IP-компьютера:9101` (если агент и сервер на одном ПК — `host.docker.internal:9101`) |
| Токен агента | из окна агента (файл `agent-token.txt`) |
| Принтер в Windows | нажмите «Найти» и выберите из списка |
| Ширина бумаги | 80 мм или 58 мм |
| Кодировка | **CP866** (по умолчанию). Если вместо русских букв «кракозябры» — попробуйте CP1251 или «Латиница» |

Нажмите **«Тест»** — принтер напечатает пробную страницу с русским текстом.

Кассовый моноблок с принтером: запустите агент на моноблоке, а в Innova365 укажите его адрес. Один принтер может печатать сразу
несколько типов документов (чеки, счета, кухня, итоги дня).

## Каждая касса — свой принтер

Если на нескольких кассах стоят свои принтеры, добавьте каждый в **Настройки → Принтеры** (адрес = IP той кассы, где запущен агент),
а на каждом компьютере в выпадающем списке «Принтер этого устройства» (на странице Кассы и в настройках) выберите его принтер.
Выбор запоминается в браузере этого компьютера, и чеки с него идут только на «свой» принтер.

## Как это работает

```
Innova365 (Docker)  ──HTTP, X-Token──▶  агент (этот ПК)  ──winspool RAW──▶  принтер (USB)
```

* `GET /health` — проверка (без токена)
* `GET /printers` — список принтеров Windows (порт, USB, офлайн, оценка «подходит для чеков»)
* `GET /best` — лучший принтер для чеков
* `GET /discover?subnet=a.b.c` — поиск сетевых принтеров (порт 9100)
* `POST /print?printer=<имя>` — тело запроса = байты ESC/POS

Агент слушает порт 9101 и требует токен; не открывайте его в интернет. Файлы: `agent.ps1` (Windows, по умолчанию) и `agent.js` (альтернатива на Node.js, в т. ч. Linux/macOS через CUPS).

## Если не печатает

| Симптом | Что проверить |
|---|---|
| «Не удалось напечатать — OpenPrinter» | Имя принтера в Innova365 точно совпадает с именем в Windows (выберите через «Найти»). |
| «El agente de impresión no respondió» | Агент запущен? Порт 9101 открыт? Адрес указан верно? |
| Неверный токен | Токен в настройках = содержимое `agent-token.txt` рядом с агентом. |
| Печатаются знаки вместо русских букв | В настройках принтера смените кодировку (CP866 → CP1251 → Латиница). |
| В окне печати браузера чек — тонкая полоска / огромная страница (принтер Xprinter XP-76 и подобные) | Драйвер сообщает бумагу «80 × 3000 мм», и браузер берёт её вместо размера чека. Не печатайте такие принтеры через окно браузера: настройте **USB / Windows через агент** (или сетевой, если у принтера есть LAN) — чек уходит прямо на принтер, без окна. |
| Принтер не режет бумагу / не открывает ящик | Включите «Отрезать бумагу» / «Открывать денежный ящик» (ящик подключается к принтеру кабелем RJ-11). |

Журнал всех заданий (успешных и ошибочных) — **Настройки → Принтеры → Журнал печати**.
Если принтер недоступен, чек не пропадает: открывается обычное окно печати браузера.
