# USB-принтер напрямую из браузера (без агента)

Один раз на кассовом ПК:

1. Подключите принтер по USB, включите. Откройте Innova365 через `start-pos-browser.bat http://194.32.142.75:8080` (Chrome с нужным флагом).
2. Скачайте **Zadig** (zadig.akeo.ie), запустите от администратора.
3. `Options → List All Devices`. В списке выберите принтер (например «XP-76» или «USB Printing Support»).
4. Справа от зелёной стрелки выберите драйвер **WinUSB** → **Replace Driver**. Дождитесь «Driver installation: SUCCESS».
5. В Innova365: оплата/печать → «USB-принтер (напрямую из браузера)» → **Подключить USB-принтер** → выберите принтер → **Проверка принтера**.

После шага 4 Windows больше не печатает на этот принтер своими приложениями — он нужен только Innova365. Вернуть как было: Диспетчер устройств → принтер → «Обновить драйвер» → «Автоматический поиск» (или переустановить драйвер Xprinter).
